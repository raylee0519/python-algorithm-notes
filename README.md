# Algorithm Practice

This repository contains my algorithm practice records organized by year and month.

The main goal is to study core algorithm concepts by solving selected Baekjoon problems and comparing how different approaches work in practice.

Rather than only collecting accepted solutions, I focus on:

* understanding the problem-solving idea
* implementing the algorithm in Python
* checking how the code actually runs
* comparing different approaches when possible
* reviewing mistakes and improving the solution

## Purpose

This repository is not only for storing correct answers.
It is a record of how I studied algorithms step by step by running code, comparing results, and understanding why each algorithm works.
